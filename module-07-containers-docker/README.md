# Module 7 - Containers with Docker

Because I work with Docker daily, I didn't follow every step of this module literally. Where the videos use `docker run` with a long list of flags, I mostly went straight to a docker compose file. The concepts are the same: images, containers, networks, volumes and a private registry.
